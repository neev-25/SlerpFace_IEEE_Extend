# Project evolution: SlerpFace inspiration to GuardFace research tools

Updated October 16, 2026.

## Research foundation

The project began with feature-template experiments inspired by the included paper, *SlerpFace: Face Template Protection via Spherical Linear Interpolation*. The local model code exposes an IR backbone, spatial group features, and attention; transformation utilities explore rotation toward noise followed by feature dropout.

The paper supplies research context, not implementation certification. This checkout does not reproduce all of its model, training, matching, privacy, or evaluation protocols. Results from the paper cannot be treated as measured results for GuardFace.

## Added demonstration layers

GuardFace added FFT spectrum analysis, texture/color heuristics, a Streamlit inspector and paired-image interface, command-line orchestration, synthetic sample/evaluation scripts, and illustrated pipeline reports. These additions made the numerical pipeline easier to inspect. They did not by themselves establish liveness or identity assurance.

Earlier documentation described the project as ready for production and made standards-compliance, attack-interception, inversion-resistance, revocation, accuracy, and throughput claims. Those claims are retired. Synthetic patterns were generated by a narrow drawing process; comparison-system results were not measured locally. Historical successful tests covered selected examples and missed false matches and transformed presentation attacks. Neither the old suite count nor a dimension-count argument substantiated the claims.

## Audit and corrected operating boundary

The October 2026 audit identified unrelated inputs authenticating, untrained statistics silently replacing trained features, heuristic sensitivity to resampling/no-face inputs, missing-input substitutions, retained shared raw-image files, misleading inspector text, and broken research entry points. It also found that claimed persistent enrollment was only transient computation.

Remediation changed the operating contract:

- Authentication is always disabled; cosines are diagnostics rather than identity decisions.
- Untrained statistics require explicit demo selection. Missing model code or weights produce actionable unavailable states rather than fallback recognition.
- Normal input processing requires one Haar-detectable face and bounds image work. Incomplete OpenCV installations report unavailable; the subsequently provisioned isolated runtime has a working classifier. Synthetic drawings bypass face presence only in explicitly labeled demonstrations.
- The dashboard retains inputs in memory, represents missing captures honestly, and reports only operations actually performed.
- Research transforms use explicit ephemeral contexts and local generators; they are not described as encryption or persisted/revocable credentials.
- Reports enforce their heuristic gate before extraction, use supported plotting APIs, and avoid intermediate raw-image files. Requested figures remain sensitive exports.
- Dataset loading validates annotations and image-folder paths. Launchers resolve their project paths independently of caller working directory and preserve process statuses. The absent original multi-stage encryption/matching pipeline fails before producing partial artifacts.

The actual implemented requirements are in [PRD.md](PRD.md), usage is in [README.md](README.md), and dated validation results and remaining limitations are in [docs/AUDIT_FIXES.md](docs/AUDIT_FIXES.md). These changes make failures visible and prevent unsupported decisions; they do not complete a biometric authentication product.

## Next research stage

The subsequent functional pass replaced the disabled camera/upload comparison path with actual local pretrained YuNet/SFace inference. Original trained cosine drives explicitly experimental similar/different/uncertain labels; transformed cosine remains a separate research measurement. MiniVision's pinned MiniFASNet checkpoints now provide an advisory learned presentation estimate. Texture rejection no longer vetoes real face comparison. Duplicate camera previews and disappearing results were corrected. See [docs/FUNCTIONAL_PROTOTYPE.md](docs/FUNCTIONAL_PROTOTYPE.md) for current behavior, measured tests, model provenance and limitations. Historical missing-weight statements below concern the original optional IR-50 architecture, not the now-provisioned default SFace backend.

The follow-up pass provisioned an isolated Python 3.11 runtime, official CPU PyTorch, a minimal pinned Tencent backbone with source integrity and license notices, and working face-detection support. Previously skipped tensor cases now run; random-weight forward/checkpoint tests establish API compatibility only. Real browser checks cover desktop/narrow light/dark layouts, invalid inputs, keyboard tabs and isolated sessions; a confirmed contrast defect was corrected. The complete Python inventory and advisory scan are recorded with a hash lock and SBOM.

Separate offline dataset tooling now enforces calibration/test subject and image separation and reports held-out errors with uncertainty. A local Windows DPAPI/SQLite research prototype adds encrypted template payloads and transactional rotation/revocation without connecting them to authentication. These tools support future evaluation; they do not manufacture evidence from missing real data. [docs/AUTONOMOUS_FOLLOWUP.md](docs/AUTONOMOUS_FOLLOWUP.md) records the final checks and limits.

Real trained inference still needs trusted compatible weights and verified weight rights. Physical presentation attacks, independent genuine/impostor identities, operational protected-match calibration, inversion/reconstruction testing, unlinkability, product credential-policy validation, and deployment testing remain external work. Any future authentication feature must be gated on those results and an explicit product policy.

Project ownership must also confirm licensing and external code/weight rights. The earlier reference to an absent project LICENSE file has been removed; no license grant is inferred.
